Create a PR review artifact. A structured review briefing for a GitHub pull request, published as a shareable page. It contains a synthesis title and bottom line, a recommendation, reviewer judgment calls, a visual explainer, signals, and blind spots. Use when the user asks to review a PR as an artifact, or publish a PR review page or briefing. NOT a narrative walkthrough. Only for CREATING a new artifact. A published composed review page is updated ONLY through the acting loop's republish. Never by editing its HTML directly.
