Turn an idea into a working proof of concept and publish it as an Artifact. A single self-contained page the user can open, click through, and react to. Run a short intake, state your assumptions, build, then iterate on feedback in the same artifact. Use when the user asks to prototype an idea, mock up a concept, or build a proof of concept. The skill also fits a user who wants to see something working before a commitment to a real build. Including, on an explicit ask, a new feature shown in place on an app they already have.
