Take a higher-resolution screenshot of a specific region of the last full-screen screenshot. Use this tool often to inspect small text, button labels, or fine UI details. These details are hard to read in the downsampled full-screen image. IMPORTANT: Coordinates in later click calls always refer to the full-screen screenshot, never the zoomed image. This tool is read-only. It inspects detail.
