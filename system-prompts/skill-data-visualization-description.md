Use this skill whenever you are about to create ANY chart, graph, plot, dashboard, or data visualization. Any output medium counts. An HTML or React artifact, inline SVG, or plotting code in any library (matplotlib, plotly, d3, Recharts, …). Also an image/PNG you will render and upload, or a chart shared into Slack. Read it BEFORE the first line of chart code, a chart color choice, or a stat tile / KPI row. Also read it before you lay out a dashboard. Produces visualizations that read as one system. Elegant, accessible, consistent in light and dark. Using a brand-neutral placeholder palette you swap for your own. Teaches a design-system-agnostic method: a form heuristic, a color formula with a runnable validator, mark specs, and interaction rules. A validated default palette is documented in `references/palette.md`. Swap that file's values for your brand's. Triggers on: "chart", "graph", "plot", "data viz", "visualization", "dashboard", "analytics", "visualize data". Also: "categorical colors", "sequential / diverging palette", "stat tile", "sparkline", "heatmap", "legend", "axis", "tooltip", "chart colors", "color by series".
