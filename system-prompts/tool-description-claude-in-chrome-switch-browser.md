Send a connection request to every Chrome browser that has the Open Claude in Chrome (browser-occ) extension. The tool waits up to 2 minutes for the user to click 'Connect' in the browser they want. The user can name the browser at connection time. Use this tool when the user wants to pick the browser from inside Chrome.
