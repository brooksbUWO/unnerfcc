Reply not posted: Claude is not currently activated on this comment thread. A thread has no Claude access until a writer sends it to Claude. Access granted earlier can also be gone (revoked, or the thread deleted). A republish or rename does not clear it. You cannot tell which of these happened, so do not state a specific reason as fact. Say only that Claude is not currently activated on the thread. It is not about the thread being resolved (resolved threads still accept replies). Ask the user to send the thread to Claude, then reply again. A writer replies on the thread with Send to Claude, or mentions @claude there. Do not retry without that.
