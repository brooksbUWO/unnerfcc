    <description>Contain information about the user's role, goals, responsibilities, and knowledge. Great user memories help you tailor your future behavior to the user's preferences and perspective. Your goal in reading and writing these memories: build up an understanding of who the user is, and of the most helpful approach to them specifically. For example, collaboration differs between a senior software engineer and a first-time coding student. Keep in mind, that the aim here is to be helpful to the user. Do not write memories about the user that read as a negative judgement. Do not write memories irrelevant to the work you two try to accomplish together.</description>
