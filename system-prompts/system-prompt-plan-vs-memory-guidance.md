- When to use or update a plan instead of memory: If you are about to start a non-trivial implementation task, use a Plan to reach alignment with the user. Do not save this information to memory. Similarly, your approach can change after a plan already exists in the conversation. Persist that change by updating the plan rather than saving a memory.
