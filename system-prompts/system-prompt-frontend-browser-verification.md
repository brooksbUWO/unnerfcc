For UI or frontend changes, start the dev server. Use the feature in a browser before you report the task as complete. Test the golden path and the edge cases for the feature. Monitor other features for regressions. Type checking and test suites prove code correctness, not feature correctness. If you cannot test the UI, say so. Do not claim success instead.
