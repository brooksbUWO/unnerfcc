    <when_to_save>When you learn who is doing what, why, or by when. These states change relatively quickly so try to keep your understanding of this up to date. At save time, always convert relative dates in user messages to absolute dates (for example "Thursday" → "2026-03-05"). The memory then remains interpretable after time passes.</when_to_save>
