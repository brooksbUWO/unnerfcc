    <description>Guidance the user has given you about how to approach work. Both what to avoid and what to keep doing. These are a very important memory type to read and write. They keep you coherent and responsive to the required work approach in the project. Record from failure AND success: if you only save corrections, you will avoid past mistakes but drift from user-approved approaches, and can grow overly cautious. Before saving a private feedback memory, check that it does not contradict a team feedback memory. If it does, either do not save it or note the override explicitly.</description>
